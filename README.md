# 🌙 Dream World — A Magical Adventure Game

**Created by Manya Verma**

Dream World is a fun, interactive fantasy platform game built using HTML, CSS, and JavaScript. Explore magical floating islands, collect glowing stars, avoid dangerous spikes, and reach the portal to unlock new worlds!

## ✨ Features

- 🎮 **Interactive Gameplay:** Move, jump, and explore a magical world.
- ⭐ **Collect Stars:** Collect five stars in each level to unlock the portal.
- 🌍 **Three Levels:** Explore three different worlds with increasing challenges.
- ❤️ **Lives System:** Get three lives to complete your adventure.
- ⏳ **Countdown Timer:** Complete the adventure before time runs out.
- 💫 **Visual Effects:** Enjoy glowing stars, floating islands, particles, and animated backgrounds.
- 📱 **Responsive Design:** Play on desktop or mobile devices.
- 🔄 **Replay Option:** Restart the game and try to improve your performance.

## 🛠️ Technologies Used

- **HTML5** — Structures the game interface.
- **CSS3** — Creates the design, layout, animations, and responsive styling.
- **JavaScript** — Handles game mechanics, movement, collision detection, scoring, and levels.
- **HTML5 Canvas** — Renders the interactive game world.

## 🚀 How to Run

1. Download or clone this project.
2. Make sure all three source files are in the same folder.
3. Open `index.html` in your web browser.
4. Click **START ADVENTURE**.
5. Explore the world and enjoy the game!

No additional software installation or backend server is required.

## 🎮 Controls

| Control | Action |
|---|---|
| Left Arrow (←) | Move left |
| Right Arrow (→) | Move right |
| Spacebar | Jump |
| Up Arrow (↑) | Jump |
